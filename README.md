# 分組求生記

可愛像素風的分組報告小遊戲。期末專題要分組了：在教室裡走動找組員，避開雷組員、找到神隊友，撐過一整學期的專題挑戰。

**線上玩：** https://iammay22.github.io/group-survival/

## 怎麼玩

1. **找組員**：每局隨機 3～6 人一組。在時間內走遍教室，先聊聊看，了解同學的個性和專長，再邀請他入組。
2. **做專題**：分工配對、喬開會時間、處理雷組員、派人解決突發狀況、期末衝刺，最後上台報告。
3. **拿成績**：依照報告進度、組內氣氛和專長完整度打分數。A+ 可不好拿。

遊戲裡有 12 種雷組員和 8 種神組員可以收集，遇到神組員還能偷學怎麼當個好隊友。

## 操作

- 手機、平板：拖動畫面下方的搖桿，或直接點畫面
- 電腦：方向鍵或 WASD，或用滑鼠點畫面
- 右上角「音效」按鈕可以開關音效和背景音樂
